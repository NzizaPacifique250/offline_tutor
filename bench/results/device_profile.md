## Reading these numbers

Total RAM sets the hard ceiling on model size. Android's low-memory killer
will terminate a foreground application well before it reaches the total, so
the practical budget for model weights plus the key-value cache is roughly
half of available RAM. Compare that budget against the model file sizes in
`results/bench_summary.md` before choosing what to ship.
