# Original grading output, preserved

These are the grading results produced on 2026-09-18, before the P1 audit
of the prototype development plan.

They are kept unchanged so that the effect of the grader corrections is
auditable. The audit found defects in answer extraction and normalisation,
not in the model responses, so the raw `.jsonl` response files are unchanged
and were not re-run.

Compare these files with the graded files one folder up to see the effect of
the grader corrections.
